# ObsidianWars

A competitive Minecraft Bedwars-style plugin with obsidian destruction mechanics.

## Overview

ObsidianWars is a feature-rich Minecraft plugin that brings Bedwars-style gameplay to your server with unique obsidian destruction mechanics. Players compete in teams to destroy each other's obsidian beds while defending their own, with the added twist that obsidian can be broken under specific conditions.

## Key Features

### Core Gameplay
- **Team-based combat**: Red vs Blue teams with customizable colors and wool types
- **Obsidian destruction**: Unique mechanics allowing obsidian to be broken during gameplay
- **Bed protection**: Teams must defend their obsidian beds - once destroyed, no respawns
- **Resource gathering**: Automatic resource spawning and mining for team upgrades
- **Kill streaks**: Track and reward consecutive kills with special effects

### Game Mechanics
- **Sudden Death mode**: After a timer, intense effects activate (wither, strength, glowing)
- **Void auto-death**: Automatic death below configurable Y-level
- **Mob spawning**: Configurable mob areas for added challenge
- **Wall system**: Bedrock walls drop after preparation phase
- **Reconnect system**: Players can rejoin within a timeout after disconnecting

### Player Experience
- **XP and leveling system**: Earn XP from kills, wins, and gameplay actions
- **Statistics tracking**: Comprehensive player stats stored in database
- **Scoreboards**: Real-time game information display
- **Tablist**: Per-world tablist with health indicators
- **Spectator mode**: Watch games after elimination

### Multi-language Support
- Built-in support for English, Spanish, and Azerbaijani
- Per-player language preferences
- Easy to add new languages via YAML files

### Integration
- **Vault economy**: Optional integration for economy rewards
- **PlaceholderAPI**: Expandable placeholders for other plugins
- **bStats metrics**: Anonymous usage statistics for plugin improvement

### Admin Tools
- **Arena setup wizard**: Step-by-step arena creation
- **World snapshots**: Save and restore arena worlds
- **Health monitoring**: System health checks and performance monitoring
- **Debug mode**: Detailed logging for troubleshooting
- **Admin commands**: Manage player levels, coins, and stats

## Requirements

- **Server**: Minecraft 1.21+ with Paper/Spigot
- **Java**: Java 21 or higher
- **Database**: SQLite (default) or MySQL
- **Optional**: Vault plugin (for economy integration)
- **Optional**: PlaceholderAPI (for placeholder support)
